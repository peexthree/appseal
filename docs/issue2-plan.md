## 2. Где брать реальные цели

**С согласием авторов (основной канал, имена публикуем):**
- призыв в конце отчёта №1: «пришлите URL» - входящий поток через лендинг
- посты в r/vibecoding, r/SideProject, Show HN с фильтром согласий
- прямые письма авторам из галерей (персонально, не массово)

**Публичные галереи (агрегаты, имена - после верификации):**
- `*.lovable.app` - публичные проекты из Lovable Explore
- `*.webcontainer.io` / bolt.new превью - проекты Bolt
- витрины Product Hunt в категории "AI App Builder" (свежие запуски)
- каталоги баз44/replit Deployments из открытых списков

**Санитарные правила скана** (уже реализовано в движке):
- 20-40 запросов на цель, таймауты 5-12 сек, конкурентность 4
- UA `AppSeal-Scanner/0.2 (+https://appmot.io/bot)`, opt-out по письму
- SSRF-guard, секреты маскируются, полные значения не хранятся

## 3. Механика прогона

1. Собрать список целей в текстовый файл (по URL на строку, `#` - комментарии)
2. `python3 scripts/appmot_benchmark.py --file targets.txt --limit 20 --tag pilot2`
3. Скрипт сохраняет полные JSON по целям в `scripts/benchmark_data/<key>.json`
4. Датасет и графики пересобираются `scripts/appmot_dataset.py` (+ графики выпуска №1)
5. Публикация: агрегаты сразу; имена - только верифицированные с согласием

## 4. GTM-эксперименты выпуска №2 (из внешнего разбора, приоритизировать самим)

- **Launch Pass $9** - разовый пропуск: безлимитные проверки одного домена на неделю
  до класса A. Проверка гипотезы: микропроекты не хотят подписку, но хотят результат
- **Pro $19/мес** - переупаковать для серийных мейкеров: 5-10 проектов, еженедельный
  мониторинг в Telegram/email, автопроверка после релиза
- **Dofollow-реестр бейджей** - класс A получает индексируемую ссылку из каталога:
  бесплатный SEO-трафик как главный аргумент поставить бейдж на первый экран
- **Platform-воронка на биржи микро-SaaS** (Acquire, Flippa, TinyAcquisitions):
  «техосмотр перед листингом» - готовая ценность за $499/мес, снижает риск скама
- **Отчёт-рейтинг платформ** - «State of Vibe-Coded App Security» выпуск №2 с
  реальной выборкой: основной PR-материал и проверка конверсии из отчёта в сканы
