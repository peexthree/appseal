## Что показал кейс

1. **Полный цикл продукта работает в бою**: скан → кнопка промпта → агент → коммит → рескан. Одна сессия, ни строчки бизнес-кода не переписано.
2. **Промпт самодостаточен**: агент без доп. контекста отличил реальные пробелы (X-Frame-Options) от автоповедения CDN (ACAO `*` на статике), не сломал ничего и корректно распознал устаревший title как проблему кэша, а не кода.
3. **Родился стандарт онбординга целей**: сайты за Vercel Challenge требуют bypass-правила для UA `AppSeal-Scanner` в Firewall - теперь часть инструкции владельцу. Сканер сообщает об этом явно (`x-vercel-mitigated: challenge`).
4. **Дистанция до класса A - один вечер**, что и утверждает вся линейка AppSeal.

## Забавная деталь для отчёта №2

Первая попытка агента "перекрыть" ACAO `*` на статике через next.config.js
не сработала - Vercel CDN продолжает автоподставлять `*` для статических
файлов на уровне CDN. Правильное место - `vercel.json` headers (CDN-уровень).
Это тонкость, которую агент нашёл сам и сам же исправил во втором коммите.
