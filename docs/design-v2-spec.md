# ТЗ: продвинутый дизайн appseal.online (лендинг, волна 3)

Статус: спецификация, не реализовано. Дата: 2026-11-14.
Объект: главная страница (src/components/scanner-page.tsx, src/app/globals.css), по касательной /registry и report-view.

## 1. Цель

Поднять визуальный уровень лендинга с "аккуратный dark-SaaS" до "премиальный продукт уровня Vercel/Linear/Resend": глубина, движение, свет. Конверсионная структура (волны 1-2) уже работает - её не менять, менять подачу.

## 2. Инварианты (не трогать)

- Вся логика: сканер, поллинг, квоты, Launch Pass, возврат из ЮKassa, consent-чекбокс, rkey-модель.
- Тексты и i18n-ключи (src/lib/i18n.ts). Новые строки - либо новые ключи, либо инлайновые объекты `{ ru, en }` как в CHECK_CATEGORIES.
- Палитра бренда: фон #090D16 / #111827 / #070B13, акцент sky-400 #38BDF8 (текст на нём #090d16), статусы emerald-400, границы slate-800. Цвета грейдов только из GRADE_META.
- Шрифты: Inter (body), Manrope (display), JetBrains Mono (mono).
- Честность CTA: никаких обещаний "полного отчёта" на публичных ссылках (урок e2a9e4b).
- Никаких длинных тире в текстах и комментариях - только дефисы.
- Порядок секций: hero -> stats -> how -> case -> registry -> checks -> pricing -> FAQ -> footer.

## 3. Глобальный ambient-слой

1. Aurora-фон: fixed-слой за контентом, 2-3 радиальных пятна (sky 10%, indigo 9%, emerald 5% прозрачности), медленный дрейф transform-анимацией 25-30с, alternate. Без hue-rotate и filter-анимаций (дорого).
2. Noise-overlay: SVG fractalNoise data-uri, opacity ~0.03-0.04, поверх aurora. Убирает "пластиковость" градиентов.
3. Существующая сетка .appseal-grid остаётся в hero.
4. Реализация: div aria-hidden pointer-events-none внутри корневого контейнера; header/main/footer получают relative z-10 (учесть painting order - фон не должен перекрывать контент и не должен прятаться под bg корневого div).
5. prefers-reduced-motion: все декоративные анимации (aurora, marquee, sheen) отключаются.

## 4. Дизайн-система (новые утилиты в globals.css)

- `.appseal-card`: стеклянная карточка - лёгкий вертикальный градиент фона (rgba(17,24,39,.92) -> rgba(13,19,32,.92)), граница slate-800, при hover: подъём translateY(-3px), граница sky-400/30, тень 0 18px 44px -22px rgba(56,189,248,.25), световая линия по верхней кромке (::before, gradient 90deg transparent -> sky/35 -> transparent, появляется opacity-переходом). Заменяет все `border-slate-800 bg-[#111827]` карточки.
- `.appseal-gradient-text`: градиентный текст sky-400 -> indigo-400 -> sky-400, background-size 200%, медленный sheen 6-8с.
- `.appseal-ring`: обёртка p-[1px] с анимированным градиентом границы (для формы сканера и featured-карточки тарифа).
- `.appseal-marquee` + `.appseal-fade-x`: бесконечная бегущая строка (translateX до -50%, дублированный контент, mask-fade по краям).
- Таймфункция reveal-анимаций: cubic-bezier(0.21, 0.6, 0.35, 1), длительность 0.5-0.6с, сдвиг y 20-24px.

## 5. Моушн-слой (framer-motion, уже в deps)

- Компонент `Reveal`: whileInView, once: true, viewport margin -80px; оборачивает контент каждой секции. Стаггер 0.06-0.1с для элементов гридов.
- Компонент `SectionHead`: eyebrow-пилюля (uppercase, tracking-[0.18em], border sky-400/20, bg sky-400/[0.06]) + заголовок text-2xl sm:text-3xl + подзаголовок. Единый вид у всех 7 секций. Тексты eyebrow - инлайновые {ru,en}: Почему/Why, Процесс/Process, Кейс/Case, Реестр/Registry, Движок/Engine, Тарифы/Pricing, FAQ.
- Компонент `Stat`: счётчик, анимируется от 0 до значения (useInView once + animate из framer-motion, ~1.2с easeOut), поддержка суффиксов (% / M) и одного знака после точки.
- Никаких scroll-jacking, parallax на скролле и sticky-сцен - только reveal и hover.

- Номер шага: крупный полупрозрачный mono-номер в углу карточки (text-5xl, slate-800) вместо мелкого.

### 6.7 Кейс

## 7. Адаптив

- Брейкпоинты существующие (sm/md). Все новые эффекты обязаны корректно деградировать на мобиле: aurora и noise остаются, hover-эффекты не критичны, ticker работает.
- Никаких горизонтальных скроллов: корневой контейнер overflow-x-clip.
- Тап-таргеты >= 40px, текущие размеры кнопок не уменьшать.

## 8. Доступность

- prefers-reduced-motion: reveal-анимации выключаются (контент виден сразу), aurora/marquee/sheen статичны, счётчики показывают конечное значение мгновенно.
- Все декоративные слои aria-hidden + pointer-events-none.
- Контраст текста не ниже текущего (slate-400 на #090d16 - нижняя граница, не светлее для body-текста).
- Фокус-стили на всех интерактивных элементах (focus-visible ring sky-400).

## 9. Производительность

- Только CSS-анимации transform/opacity; никаких анимаций filter, box-shadow в keyframes (hover-переход тени допустим), width/height.
- Без новых зависимостей: framer-motion + tailwind уже есть. Никаких tsparticles, three.js, lottie.
- Noise - инлайновый data-uri (< 1 КБ), без запросов.
- LCP не ухудшать: hero-текст не оборачивать в reveal с задержкой > 0.1с (или рендерить видимым и анимировать только декор).
- Бандл: прирост клиентского JS < 5 КБ.

## 10. Технические ограничения проекта

- Mimosa-гейт: не использовать regex.exec() (флаг command injection) - только String.match; пути к файлам не строить динамически.
- Исходники менять только через Write/Edit (не через Bash).
- Сборка: Node 22 + npm, next build; тесты node --test с --experimental-strip-types, в Git Bash передавать tests/*.test.ts явно.
- Деплой: push в main -> Vercel auto-deploy (либо npx vercel deploy --prod --token из D:\BIR\.env).

## 11. Критерии приёмки

1. npm run build проходит, 30/30 тестов зелёные.
2. Визуально: aurora+noise фон, градиентный hero-акцент, ticker, анимированные счётчики, reveal секций, hover-глоу карточек - всё присутствует на проде.
3. Поведение сканера/оплаты/квот не изменилось (ручной прогон: скан demo://app, чипсы, форма LP до редиректа в ЮKassa).
4. prefers-reduced-motion: страница полностью статична, контент доступен.
5. Мобильный вид 375px: без горизонтального скролла, меню и формы работают.
6. Lighthouse (mobile): Performance и Accessibility не ниже текущих значений.
7. Нет длинных тире ни в одной новой строке.
